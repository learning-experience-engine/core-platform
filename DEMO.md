# Demo Walkthrough (10 minutes)

## Run
```bash
pnpm install
pnpm dev
```

Open: http://localhost:5173

Try these experiences

A. Deep-dive card stack (context-preserving)
	1.	Start at Plant Cell
	2.	Click a highlighted term (e.g., Protoplast)
	3.	Click another term inside the new card (e.g., Membrane / Bacteria)
	4.	Use the breadcrumb chips at the top to go back

B. Facet-based relations (multi-dimensional exploration)

On any card:
	•	Go to RELATIONS
	•	Switch tabs:
	•	是什么 / 怎么实现 / 生活体现 / 差异对比 / 动手实践
	•	Click any relation chip to navigate

C. Neighborhood graph (1-hop)

On any card:
	•	Go to NEIGHBORHOOD
	•	Switch facet filters + Graph/List view
	•	Click neighbors to navigate (URL updates)

D. Question chain (guided learning)

On nodes with a chain:
	•	Click Start Question Chain
	•	Switch Child/Adult
	•	Use Prev/Next
	•	Click highlighted terms inside answers to deep-dive without losing the chain
